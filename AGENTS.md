## Critical Patterns

1. Generator Support: This package extends Mocha to support generator functions in tests.
2. Runtime Extension: The package modifies Mocha's `Runnable.prototype.run` method at runtime to enable generator support.

Example usage:

```javascript
describe("New user", function() {
  let business;
  let user;

  before(function*() {
    yield setup();
    business = yield Account.create("FooBar Inc");
    user = yield business.addUser("Mr. Boo");
  });

  it("should be the only customer", function*() {
    let count = yield User.count({ businessID: business.id });
    assert.equal(count, 1);
  });

  after(function*() {
    yield cleanUp();
  });
});
```

## Common Pitfalls to Avoid

1. Forgetting to require `few-mocha` before using generator functions in tests
2. Mixing async/await syntax with generator functions in the same test suite
